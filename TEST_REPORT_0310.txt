一、本版改动（0.3.10）
--------------------
jb_find 直接接受设备路径，自动落到系统目录（系统优先）：
  /var/mobile/Documents   -> /rootfs/private/var/mobile/Documents
  /System/Library/Fonts   -> /rootfs/System/Library/Fonts
  /rootfs/...             -> 原样使用
加 jailbreak=true 改为搜索越狱目录（jbroot）。jb_maintenance_info 的 paths 字段给出
system / jailbreak 两条根路径与 prefer="system"。

三、本轮真机验证（iPhone15,3 / iOS 16.4.1 / Dopamine Roothide）
---------------------------------------------------------------
- 自更新通道部署 bridge 0.3.8：stage -> validate -> apply，约 6 秒，healthy，token 不变。
- /System/Library/Fonts -> /rootfs/System/Library/Fonts，命中 PingFang.ttc、ADTTime.ttc 等。
- /var/mobile/Documents -> /rootfs/private/var/mobile/Documents，命中 5 个 ipa
  （含 光·遇_0.15.6.ipa 2247737734 字节）。
- 同一路径 + jailbreak=true -> jbroot 的 Documents（越狱目录）。
- 默认不带 path -> /rootfs/private/var/mobile（系统目录）。
